## 1. מטרה והקשר

מסמך זה מגדיר **3 כיווני עיצוב (Design System)** לאתר הלקוחות של Maison Malka — קונדיטוריה בוטיק פרימיום בירושלים.

**מקורות:**
- [`Maison-Malka-PRD.md`](./Maison-Malka-PRD.md) — יוקרה, אלגנטיות, תחושת "וואו, אני רוצה להזמין"
- [`phases/01-foundation-and-brand.md`](./phases/01-foundation-and-brand.md) — מערכת עיצוב + דף בית
- Skill: `ui-ux-pro-max` — המלצות עיצוב מעובדות (לא העתקה גולמית)

**קהל יעד:**
- לקוח פרטי — מחפש מוצרים איכותיים, מתרשם מתמונות, מזמין לאירועים/מתנה
- מנהל העסק — ממשק אדמין נפרד (עברית, Phase 1)

**טכנולוגיה (יישום עתידי):**
- Next.js App Router + Tailwind CSS
- RTL לעברית + LTR לאנגלית (Phase 2)
- תמונות מוצר מ-Supabase Storage

**תחושה רצויה (מכל הכיוונים):**
> "וואו, הכול נראה כל כך טעים — אני רוצה להזמין עכשיו."

## 2. עקרונות משותפים (כל הכיוונים)

חלים על כל כיוון עיצובי, ללא קשר לבחירה הסופית.

### תוכן ויזואלי
- תמונות מוצר באיכות גבוהה — לא placeholder גנרי
- דגש על טקסטורה, צבע ופרזנטציה של המוצר
- לוגו ומיתוג Maison Malka בולטים אך לא דומיננטיים מדי

### אייקונים ואינטראקציה
- **אין אמוג'י כאייקונים** — השתמשו ב-Lucide או Heroicons (SVG)
- `cursor-pointer` על כל אלמנט לחיץ (כרטיסים, קישורים, כפתורים)
- Hover: מעבר חלק 150–300ms (צבע, צל, גבול)
- Focus states גלויים לניווט מקלדת
- `prefers-reduced-motion` — כבדו העדפות נגישות

### נגישות ורספונסיביות
- ניגודיות טקסט: מינימום WCAG AA (4.5:1)
- רספונסיביות: 375px, 768px, 1024px, 1440px
- כל תמונה עם `alt` תיאורי
- שדות טופס עם תוויות (labels)

### שפה וכיווניות
- עברית (RTL) — שפת ברירת מחדל
- אנגלית (LTR) — Phase 2, מתג שפה
- אדמין — עברית בלבד ב-Phase 1 (ממשק נפרד, לא חלק ממסמך זה)

### מבנה דפים משותף (אתר לקוחות)

```text
דף בית:     Hero → קטגוריות → מוצרים מומלצים → CTA הזמנה → Footer
קטלוג:      סינון קטגוריה → רשת מוצרים → pagination (עתידי)
עמוד מוצר:  גלריה → שם/תיאור → מחיר → אפשרויות → הוסף לעגלה
```

## 3. כיוון A — Boutique Noir & Gold

### תחושה / Mood

**"בוטיק יוקרתי עם נגיעת זהב — אלגנטיות שקטה שמעוררת רצון להזמין."**

מילות מפתח: luxury, boutique, premium, elegant, refined, Jerusalem

### פלטת צבעים

| תפקיד | Hex | שימוש |
|--------|-----|--------|
| Primary | `#1C1917` | כותרות, navbar, אלמנטים דומיננטיים |
| Secondary | `#44403C` | טקסט משני, גבולות עדינים |
| CTA | `#CA8A04` | כפתורי הזמנה, קישורי פעולה |
| Background | `#FAFAF9` | רקע עמוד (stone-50) |
| Text | `#0C0A09` | גוף טקסט ראשי |
| Accent | `#D4AF37` | הדגשות זהב (מחירים, badges) |

### טיפוגרפיה

| תפקיד | פונט | משקל |
|--------|------|------|
| כותרות | Cormorant | 500–700 |
| גוף | Montserrat | 300–600 |

**Google Fonts:**
https://fonts.google.com/share?selection.family=Cormorant:wght@400;500;600;700|Montserrat:wght@300;400;500;600;700

```css
@import url('https://fonts.googleapis.com/css2?family=Cormorant:wght@400;500;600;700&family=Montserrat:wght@300;400;500;600;700&display=swap');
```

### סגנון UI

| מאפיין | ערך |
|--------|-----|
| צללים | `shadow-sm` / `shadow-md` עדינים — לא glass כבד |
| רדיוס | `rounded-lg` (8px) לכרטיסים, `rounded-md` לכפתורים |
| מרווחים | `max-w-6xl` לתוכן, `py-16`–`py-24` לסקשנים |
| כפתור CTA | רקע `#CA8A04`, טקסט לבן, hover כהה יותר `#A16207` |
| כרטיס מוצר | רקע לבן, גבול `stone-200`, hover `border-amber-300` |

### מבנה דפים

**Pattern:** Feature-Rich Showcase

1. **Hero** — תמונת מוצר דגל מלאה, כותרת Cormorant, CTA "הזמינו עכשיו" מעל הקיפול
2. **קטגוריות** — 3–4 כרטיסים עם תמונה + שם (עוגות, מאפים, מארזים)
3. **מוצרים מומלצים** — רשת 3 עמודות, מחיר בזהב
4. **מארזים** — סקשן ייעודי למארזי מתנה
5. **CTA סיום** — "מוכנים להזמין?" + כפתור לקטלוג
6. **Footer** — לוגו, ירושלים, קישורי ניווט, רשתות (עתידי)

### רכיבים מרכזיים

| רכיב | תיאור |
|------|--------|
| **Navbar** | שקוף על Hero, הופך ללבן בגלילה; לוגו שמאל, ניווט מרכז, עגלה ימין |
| **כרטיס מוצר** | תמונה 4:3, שם, מחיר בזהב, hover shadow |
| **כפתור הזמנה** | זהב מלא, `px-6 py-3`, font-medium |
| **Footer** | רקע `#1C1917`, טקסט בהיר, מינימלי |

### Anti-patterns (להימנע)

- צבעים ניאון או ורודים "AI gradient"
- אנימציות glass/blur כבדות (ביצועים + ניגודיות)
- אמוג'י כאייקונים
- טקסט אפור בהיר על רקע לבן (`slate-400` לגוף)
- Navbar דבוק ל-`top-0` בלי ריווח

### התאמה לפרויקט

| | |
|---|---|
| **יתרונות** | הכי קרוב ל-PRD (יוקרה, בוטיק); מבדיל ממאפיות רגילות; מתאים למארזי מתנה |
| **חסרונות** | פחות "חם וביתי"; דורש צילום מוצר באיכות גבוהה |

## 4. כיוון B — Artisan Chaud

### תחושה / Mood

**"מאפייה אומנותית בירושלים — חום, אמינות, וטעם שמרגישים בבית."**

מילות מפתח: artisan, warm, organic, handmade, Jerusalem, cozy

### פלטת צבעים

| תפקיד | Hex | שימוש |
|--------|-----|--------|
| Primary | `#92400E` | כותרות, navbar, אלמנטים מובילים |
| Secondary | `#B45309` | הדגשות, גבולות חמים |
| CTA | `#78350F` | כפתורי הזמנה (חום כהה על רקע קרם) |
| Background | `#FEF3C7` | רקע עמוד (amber-100) |
| Text | `#78350F` | גוף טקסט |
| Accent | `#F59E0B` | badges, מבצעים (עתידי) |

### טיפוגרפיה

| תפקיד | פונט | משקל |
|--------|------|------|
| כותרות | Fraunces | 500–700 |
| גוף | Source Sans 3 | 400–600 |

**הערה:** נבחרו במקום Amatic SC (ידני מדי) — Fraunces שומר על אופי אומנותי עם קריאות טובה.

**Google Fonts:**
https://fonts.google.com/share?selection.family=Fraunces:wght@400;500;600;700|Source+Sans+3:wght@400;500;600;700

```css
@import url('https://fonts.googleapis.com/css2?family=Fraunces:wght@400;500;600;700&family=Source+Sans+3:wght@400;500;600;700&display=swap');
```

### סגנון UI

| מאפיין | ערך |
|--------|-----|
| צללים | `shadow-sm` — עדין, לא דרמטי |
| רדיוס | `rounded-xl` (12px) — רך יותר |
| מרווחים | סקשנים גדולים (`gap-12`), תחושת אוויר |
| כפתור CTA | רקע `#78350F`, טקסט `#FEF3C7`, hover `#92400E` |
| כרטיס מוצר | רקע לבן/קרם, גבול `amber-200`, תמונה גדולה |

**לא:** סגנון Vibrant & Block-based (בלוקים גיאומטריים צבעוניים) — נשמרת פריסה נקייה.

### מבנה דפים

**Pattern:** Hero-Centric + Conversion

1. **Hero** — תמונה גדולה של מאפים/עוגות, כותרת Fraunces, משפט מותג קצר
2. **סיפור מותג** — פסקה על איכות, חומרי גלם, ירושלים
3. **קטגוריות** — כרטיסים חמים עם אייקון + שם
4. **מוצרים נבחרים** — רשת 2–3 עמודות
5. **CTA** — "גלו את התפריט המלא"
6. **Footer** — פשוט, פרטי קשר, שעות (עתידי)

### רכיבים מרכזיים

| רכיב | תיאור |
|------|--------|
| **Navbar** | רקע קרם שקוף, לוגו + ניווט, עגלה |
| **כרטיס מוצר** | תמונה דומיננטית, שם, מחיר, כפתור "הוסף" עדין |
| **כפתור הזמנה** | חום כהה על קרם, rounded-xl |
| **Footer** | רקע `#92400E`, טקסט קרם |

### Anti-patterns (להימנע)

- בלוקים גיאומטריים צבעוניים (duotone aggressive)
- פונטים "כתב יד" לגוף טקסט (קריאות נמוכה)
- תמונות באיכות נמוכה
- שעות פתיחה לא מעודכנות (אם יוצגו)

### התאמה לפרויקט

| | |
|---|---|
| **יתרונות** | חם ומזמין; מרגיש מקומי ואותנטי; קל ליישום |
| **חסרונות** | פחות "פרימיום בוטיק"; עלול להיראות דומה למאפיות אחרות |

## 5. כיוון C — Editorial Blanc

### תחושה / Mood

**"מגזין קולינרי מינימליסטי — יוקרה שקטה, דגש על צילום וטיפוגרפיה."**

מילות מפתח: editorial, minimal, luxury, sophisticated, magazine, timeless

### פלטת צבעים

| תפקיד | Hex | שימוש |
|--------|-----|--------|
| Primary | `#18181B` | כותרות, navbar |
| Secondary | `#3F3F46` | טקסט משני |
| CTA | `#BE8A5C` | כפתורי הזמנה (caramel — מותאם לקונדיטוריה) |
| Background | `#FAFAFA` | רקע עמוד |
| Text | `#09090B` | גוף טקסט |
| Accent | `#A8A29E` | קווים, מפרידים (stone) |

**הערה:** CTA שונה מ-`#EC4899` (ורוד) שה-skill הציע — לא מתאים לקונדיטוריה.

### טיפוגרפיה

| תפקיד | פונט | משקל |
|--------|------|------|
| כותרות | Playfair Display | 500–700 |
| גוף | Inter | 300–600 |

**Google Fonts:**
https://fonts.google.com/share?selection.family=Inter:wght@300;400;500;600;700|Playfair+Display:wght@400;500;600;700

```css
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700&family=Playfair+Display:wght@400;500;600;700&display=swap');
```

### סגנון UI

| מאפיין | ערך |
|--------|-----|
| צללים | מינימליים או ללא |
| רדיוס | `rounded-none` או `rounded-sm` — קווים נקיים |
| מרווחים | whitespace רב, `max-w-4xl` לטקסט, `py-24`+ |
| כפתור CTA | רקע `#BE8A5C`, טקסט לבן, גדול ומרכזי |
| כרטיס מוצר | תמונה מלאה, שם מתחת, מחיר — ללא מסגרת |

### מבנה דפים

**Pattern:** Minimal Single Column

1. **Hero** — כותרת Playfair גדולה, תת-כותרת קצרה, CTA מרכזי אחד
2. **תמונת מוצר דגל** — full-width, ללא טקסט על התמונה
3. **תיאור מותג** — פסקה אחת, ממורכזת
4. **3 מוצרים** — תמונה + שם + מחיר, פריסה אנכית או 3 עמודות דקות
5. **CTA** — כפתור גדול "לקטלוג המלא"
6. **Footer** — שורה אחת, מינימלי

### רכיבים מרכזיים

| רכיב | תיאור |
|------|--------|
| **Navbar** | לוגו בלבד או לוגו + 2 קישורים; ללא clutter |
| **כרטיס מוצר** | תמונה דומיננטית, טקסט מינימלי מתחת |
| **כפתור הזמנה** | caramel, גדול, ממורכז |
| **Footer** | טקסט אפור, שורה אחת |

### Anti-patterns (להימנע)

- עומס אלמנטים ב-navbar
- צבעים playful או ורודים
- אנימציות glass כבדות
- יותר מ-3 bullets ב-Hero

### התאמה לפרויקט

| | |
|---|---|
| **יתרונות** | יוקרה שקטה; ביצועים מצוינים; בולט בזכות מינימליזם |
| **חסרונות** | פחות "חם"; דורש צילום ברמה גבוהה מאוד; פחות מידע על המסך |
