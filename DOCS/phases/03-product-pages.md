# פאזה 03 — עמודי מוצר

**קבוצה:** MVP  
**תלות:** פאזה 02  
**מקור:** PRD §7 (עמודי מוצר, תמונות ותיאורים)

---

## מטרה

לתת ללקוח חוויית צפייה עשירה בכל מוצר — תמונות, תיאור מפורט ומידע להזמנה.

## מה הפאזה עושה

1. עמוד מוצר ייעודי לכל פריט בקטלוג.
2. תמונה ראשית + גלריה (אם רלוונטי).
3. תיאור מלא, מחיר, סטטוס זמינות.
4. כפתור "הוסף לעגלה" (פעיל רק למוצר זמין — העגלה עצמה בפאזה 04).
5. breadcrumb / ניווט חזרה לקטלוג.

## בטווח

- URL ייחודי לכל מוצר.
- תצוגת תמונות איכותית (lazy loading).
- תיאור טקסטואלי.
- כפתור הוספה לעגלה (UI בלבד אם העגלה עדיין לא קיימת).

## מחוץ לטווח

- לוגיקת עגלה מלאה (פאזה 04).
- התאמות מוצר מורכבות.
- המלצות מוצרים (שלב 2).

## תוצאה ניתנת לבדיקה

```text
→ לוחצים על מוצר מהקטלוג
→ רואים עמוד עם תמונה, תיאור ומחיר
→ כפתור "הוסף לעגלה" מוצג למוצר זמין
→ מוצר לא זמין — הכפתור מושבת או מוסתר
```

## קריטריוני קבלה

- [ ] כל מוצר בקטלוג נפתח בעמוד ייעודי.
- [ ] תמונות נטענות ומוצגות כראוי.
- [ ] מצב זמינות ברור למשתמש.
- [ ] ניווט חזרה לקטלוג עובד.
