# פאזה 01 — תשתית ואתר מותג

**קבוצה:** MVP  
**תלות:** אין (פאזת פתיחה)  
**מקור:** PRD §7, §14 Phase 1

---

## מטרה

להקים את שלד הפרויקט וליצור נוכחות דיגיטלית ראשונית שמשקפת את המותג הפרימיום של Maison Malka.

## מה הפאזה עושה

1. בחירה והקמה של סטאק טכנולוגי (frontend, backend, DB — לפי החלטת ארכיטקטורה).
2. מבנה תיקיות, סביבות פיתוח, והרצה מקומית.
3. עיצוב מערכת (צבעים, טיפוגרפיה, ריווח) בהתאם ליוקרה ואלגנטיות.
4. דף בית עם:
   - הצגת המותג והערך (איכות, טעם, עיצוב).
   - ניווט בסיסי (בית, קטלוג — יכול להיות placeholder).
   - תחושת "וואו, אני רוצה להזמין".

## בטווח (In Scope)

- אתחול repo ותלויות.
- README עם הוראות הרצה.
- Layout ראשי (header, footer, ניווט).
- דף בית רספונסיבי (מובייל + דסקטופ).
- placeholder לעמודים עתידיים (קטלוג, עגלה).

## מחוץ לטווח (Out of Scope)

- מוצרים אמיתיים בקטלוג.
- עגלה, התחברות, תשלום.
- אזור מנהל.

## תוצאה ניתנת לבדיקה

```text
npm run dev  (או פקודה מקבילה)
→ פותחים את האתר בדפדפן
→ רואים דף בית מעוצב של Maison Malka
→ ניווט עובד (גם אם קישורים מובילים ל-placeholder)
```
