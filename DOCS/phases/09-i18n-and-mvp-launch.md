# פאזה 09 — רב-לשוניות והשקת MVP

**קבוצה:** MVP  
**תלות:** פאזות 01–08  
**מקור:** PRD §10 (שפות), §8 (Out of Scope validation)

---

## מטרה

להשלים את ה-MVP עם תמיכה בעברית ואנגלית, ליטוש חוויית משתמש והכנה להשקה.

## מה הפאזה עושה

1. **i18n:** עברית (ברירת מחדל) + אנגלית.
2. מתג שפה ב-header.
3. תרגום כל המחרוזות בצד לקוח ומנהל.
4. תמיכה ב-RTL לעברית.
5. ליטוש UX: מעברים, הודעות שגיאה, empty states.
6. בדיקות end-to-end לזרימת MVP המלאה (PRD §9).
7. הגדרות production: env, deploy, domain.
8. תיעוד הפעלה ומגבלות ידועות.

## בטווח

- כל המסכים הציבוריים דו-לשוניים.
- אזור מנהל דו-לשוני (לפחות ממשק בסיסי).
- RTL תקין בעברית.
- README / מדריך הפעלה מעודכן.
- deploy לסביבת staging/production.

## מחוץ לטווח

- תכונות שלב 2 ו-3.
- SEO מתקדם (אופציונלי — יכול להיכלל חלקית).
