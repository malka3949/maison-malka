# פאזה 10 — צמיחה ושימור לקוחות

**קבוצה:** שלב 2 (Post-MVP)  
**תלות:** פאזה 09 (MVP מושק)  
**מקור:** PRD §14 Phase 2, §8 (Out of Scope ב-MVP)

---

## מטרה

לשפר המרות ולקוחות חוזרים, ולהרחיב יכולות ניהול מעבר ל-MVP הבסיסי.

## מה הפאזה עושה

1. **לקוחות חוזרים:**
   - היסטוריית הזמנות למשתמש.
   - הזמנה חוזרת / מועדפים (לפי עדיפות).
2. **מבצעים:**
   - קופונים / הנחות בסיסיות.
   - מבצעים לפי תקופה.
3. **המלצות מוצרים:**
   - "לקוחות שקנו X קנו גם Y".
   - מוצרים מומלצים בדף בית / עמוד מוצר.
4. **הרחבת ניהול:**
   - דוחות בסיסיים (הזמנות לפי תקופה).
   - ניהול קטגוריות / מארזים (אם הוחלט).
   - מוצרים עונתיים.

## בטווח (טיוטה — לאשר לפני פיתוח)

- היסטוריית הזמנות בפרופיל משתמש.
- מערכת קופונים פשוטה (קוד + אחוז/סכום).
- בלוק המלצות בעמוד מוצר.
- דוח מכירות שבועי/חודשי למנהל.

## מחוץ לטווח

- CRM מלא.
- תוכנית נאמנות מורכבת.
- אוטומציות שיווק (שלב 3).

## תוצאה ניתנת לבדיקה

```text
→ לקוח רשום רואה הזמנות קודמות
→ מפעיל קופון ב-checkout — מחיר מתעדכן
→ בעמוד מוצר רואים המלצות
→ מנהל יוצר מבצע ורואה דוח מכירות
```

## קריטריוני קבלה

- [ ] היסטוריית הזמנות זמינה למשתמש מחובר.
- [ ] קופון תקף מפחית מחיר ב-checkout.
- [ ] המלצות מוצגות לפחות בעמוד מוצר אחד.
- [ ] מנהל רואה דוח בסיסי.

## הערות

פאזה זו דורשת **אישור מפורש** לאחר ניתוח נתונים מ-MVP (מדדי PRD §6).
