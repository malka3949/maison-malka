## מטרה

לשפר המרות (גל 1) ואז שימור ותפעול (גל 2), מעבר ל-MVP הבסיסי.

---

## גל 1 — המרה (Team Yuri Phase 8)

### בטווח

1. **קופונים / מבצעים בסיסיים** — קוד + אחוז או סכום קבוע ב-checkout
2. **תשלום אונליין** — שער תשלומים (ספק יינעל לפני תכנון Architect)
3. **המלצות מוצרים** — לפחות בעמוד מוצר (+ אופציונלי בדף בית)
4. **היסטוריית הזמנות + הזמנה חוזרת** — ללקוח רשום

### מחוץ לטווח (גל 1)

- WhatsApp/SMS, נאמנות, מוצרים עונתיים (גל 2)
- אזורי משלוח מעבר לירושלים, cap יומי (גל 3)
- **קמפיין מייל / broadcast שיווקי** (גל 3 — ראו [../features/marketing-email-campaigns.md](../features/marketing-email-campaigns.md))
- מלאי אוטומטי, CRM מלא, התאמות מתקדמות, ניהול ייצור (גל 4)

### תוצאה ניתנת לבדיקה (גל 1)

```text
→ קופון תקף מפחית מחיר ב-checkout
→ נתיב תשלום אונליין (מצב בדיקה) מסתיים בהזמנה תקינה
→ בעמוד מוצר מוצגות המלצות
→ לקוח מחובר רואה היסטוריה ומבצע הזמנה חוזרת
```

### קריטריוני קבלה (גל 1)

- [ ] קופון תקף מעדכן סה״כ ב-checkout
- [ ] ספק תשלום משולב לפי החלטת ספק שננעלה
- [ ] המלצות מוצגות לפחות בעמוד מוצר אחד
- [ ] היסטוריית הזמנות + reorder זמינים למשתמש מחובר

### שאלות פתוחות (גל 1)

- ספק תשלום (Stripe / ספק ישראלי / אחר)
- האם קופונים מצטברים עם תשלום אונליין ב-v1

## גל 2 — שימור ותפעול (Team Yuri Phase 9)

### בטווח

1. **WhatsApp ו/או SMS** — התראות טרנזקציוניות קודם
2. **דוחות מנהל בסיסיים** — הזמנות/הכנסות לפי תקופה
3. **מוצרים עונתיים** — תזמון חלונות זמינות
4. **נאמנות פשוטה** — נקודות או חותמות (לא CRM מלא)

### מחוץ לטווח (גל 2)

- מנועי אזורי משלוח ו-cap יומי (גל 3)
- Broadcast שיווקי ידני (גל 3)
- CRM מלא / מלאי אוטומטי / ניהול ייצור (גל 4)

### תוצאה ניתנת לבדיקה (גל 2)

```text
→ מנהל רואה דוח לפי תקופה
→ מוצר עונתי מתחלף זמין/לא לפי לוח זמנים
→ לקוח מקבל WhatsApp/SMS באירוע הזמנה מוגדר
→ יתרת נאמנות פשוטה מתעדכנת אחרי הזמנה מאושרת
```

### קריטריוני קבלה (גל 2)

- [ ] דוח תקופתי זמין באדמין
- [ ] תזמון עונתי משפיע על זמינות
- [ ] הודעת WhatsApp/SMS נשלחת באירוע מוגדר
- [ ] מודל נאמנות פשוט פעיל מקצה לקצה

### שאלות פתוחות (גל 2)

- עדיפות WhatsApp מול SMS
- מודל נאמנות: נקודות מול כרטיס חותמות
