# פאזה 11 — התרחבות ואוטומציה

**קבוצה:** שלב 3  
**תלות:** פאזה 10  
**מקור:** PRD §14 Phase 3, §10 (אזור שירות עתידי), §12 (עומס הזמנות)

---

## מטרה

להרחיב את העסק מעבר לירושלים, לשפר יכולות הזמנה מתקדמות ולהוסיף אוטומציות שיווק.

## מה הפאזה עושה

1. **הרחבת אזורי משלוח:**
   - הגדרת אזורים / ערים נוספות.
   - תמחור משלוח לפי אזור.
   - ולידציית כתובת לפי אזור שירות.
2. **יכולות הזמנה מתקדמות:**
   - הגבלת כמות הזמנות ליום (פתרון לעומס ייצור).
   - חלונות זמן למשלוח.
   - הזמנות חוזרות / מנוי (אופציונלי).
3. **אוטומציות שיווק:**
   - אימיילים אוטומטיים (אישור, תזכורת, חזרה ללקוח).
   - התראות למנהל (הזמנה חדשה, סף עומס).
   - אינטגרציה עם רשתות / pixel (לפי צורך).

## בטווח (טיוטה — לאשר לפני פיתוח)

- ניהול אזורי משלוח בממשק מנהל.
- cap יומי להזמנות עם הודעה ללקוח כשהתאריך מלא.
- אימייל אוטומטי לאחר הזמנה.

## מחוץ לטווח

- ניהול מלאי אוטומטי מלא.
- ניהול ייצור (production management).
- אפליקציה native.

## תוצאה ניתנת לבדיקה

```text
→ מנהל מוסיף אזור משלוח חדש
→ לקוח מחוץ לירושלים באזור מוגדר יכול להזמין
→ תאריך שמגיע ל-cap יומי — חסום עם הודעה
→ לקוח מקבל אימייל אוטומטי לאחר הזמנה
```

## קריטריוני קבלה

- [ ] לפחות אזור משלוח נוסף פעיל מעבר לירושלים.
- [ ] הגבלת הזמנות ליום עובדת.
- [ ] אימייל אוטומטי נשלח לאחר הזמנה מוצלחת.

## הערות

פאזה זו מותנית בצמיחת העסק ובנתונים מאז השקת MVP. יש לתעדף לפי צרכים עסקיים אמיתיים.
