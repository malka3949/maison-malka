# פאזה 07 — ניהול מוצרים (אזור מנהל)

**קבוצה:** MVP  
**תלות:** פאזה 02 (מודל מוצר), מומלץ לאחר 06  
**מקור:** PRD §7 (אזור מנהל — מוצרים), §10 (זמינות)

---

## מטרה

לאפשר למנהל העסק לנהל את קטלוג המוצרים ללא עריכת קוד.

## מה הפאזה עושה

1. כניסה לאזור מנהל (הגנה בסיסמה / role admin).
2. רשימת מוצרים עם חיפוש/סינון בסיסי.
3. **הוספת מוצר:** שם, תיאור, מחיר, תמונות.
4. **עזר כתיבה מקומי** — שם באנגלית מתמלא מהמילון (blur) כשהשדה ריק;
   כפתור **«תרגם לאנגלית»** מנסה מילון ואז Gemini חינמי (אופציונלי, `GEMINI_API_KEY`);
   כפתור **«הצע תיאור»** יוצר טיוטת תיאור HE/EN בלי API.
5. **עריכת מוצר** קיים.
6. **שינוי מחיר.**
7. **העלאת תמונות.**
8. **סימון זמין / לא זמין** (ניהול ידני — ללא מלאי אוטומטי).
9. שינויים משתקפים מיד בצד הלקוח (קטלוג + עמוד מוצר).

## בטווח

- CRUD מלא למוצרים.
- העלאת תמונות (storage מוגדר).
- toggle זמינות.
- הגנת גישה — רק מנהל.

## מחוץ לטווח

- ניהול מלאי אוטומטי.
- קטגוריות מורכבות / מוצרים עונתיים (אלא אם הוחלט אחרת).
- ניהול הזמנות (פאזה 08).

## תוצאה ניתנת לבדיקה

```text
→ מנהל מתחבר לאזור הניהול
→ מוסיף מוצר חדש עם תמונה ומחיר
→ המוצר מופיע בקטלוג הציבורי
→ מסמן מוצר כ"לא זמין" — נעלם/מסומן באתר הלקוח
→ עורך מחיר — המחיר מתעדכן באתר
```
