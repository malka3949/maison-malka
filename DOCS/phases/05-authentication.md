# פאזה 05 — הרשמה והתחברות

**קבוצה:** MVP  
**תלות:** פאזה 04  
**מקור:** PRD §7 (הרשמה והתחברות), §9 (שלב 5 בזרימת MVP)

---

## מטרה

לאפשר ללקוח לגלוש חופשי, ולהירשם / להתחבר **רק בעת ביצוע הזמנה** — כפי שמוגדר ב-MVP.

## מה הפאזה עושה

1. טפסי הרשמה והתחברות.
2. שמירת פרטי משתמש (שם, אימייל, טלפון).
3. אימות סיסמה / magic link / OAuth — לפי החלטת ארכיטקטורה.
4. מיזוג עגלת אורח לעגלת משתמש לאחר התחברות.
5. הגנה על נתיבי checkout (דורשים משתמש מחובר).
6. התנתקות.

## בטווח

- הרשמה עם שדות מינימליים להזמנה.
- התחברות משתמש קיים.
- session מאובטח.
- redirect חזרה ל-checkout לאחר auth.

## מחוץ לטווח

- פרופיל משתמש מורחב.
- שחזור סיסמה (אופציונלי — אם נדרש ל-MVP יש לכלול).
- תוכנית נאמנות (שלב 2).

## תוצאה ניתנת לבדיקה

```text
→ גולשים בקטלוג ללא התחברות
→ מוסיפים לעגלה ולוחצים "המשך להזמנה"
→ נדרשים להירשם או להתחבר
→ לאחר הרשמה — חוזרים ל-checkout עם העגלה שמורה
```

- [ ] עגלת אורח נשמרת לאחר auth.
- [ ] נתיב checkout חסום למשתמש לא מחובר.
