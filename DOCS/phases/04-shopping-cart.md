# פאזה 04 — עגלת קניות

**קבוצה:** MVP  
**תלות:** פאזה 03  
**מקור:** PRD §7 (עגלת קניות), §9 (שלב 4 בזרימת MVP)

---

## מטרה

לאפשר ללקוח להוסיף מוצרים לעגלה, לעדכן כמויות ולהמשיך להזמנה — **ללא צורך בהרשמה עדיין**.

## מה הפאזה עושה

1. הוספת מוצר לעגלה מעמוד מוצר / קטלוג.
2. עמוד עגלה: רשימת פריטים, כמויות, סכום ביניים.
3. עדכון כמות והסרת פריט.
4. שמירת עגלה (session / local storage — לפי ארכיטקטורה).
5. כפתור "המשך להזמנה" (מוביל ל-auth בפאזה 05).
6. מניעת הוספת מוצר לא זמין.

## בטווח

- עגלת אורח (ללא התחברות).
- חישוב סכום כולל.
- אינדיקטור כמות בעגלה ב-header.
- ולידציה: מוצר לא זמין לא נכנס לעגלה.

## מחוץ לטווח

- הרשמה והתחברות (פאזה 05).
- checkout ותשלום (פאזה 06).
- קופונים (שלב 2).

## תוצאה ניתנת לבדיקה

```text
→ מוסיפים 2 מוצרים שונים לעגלה
→ פותחים עמוד עגלה — רואים פריטים וסכום
→ משנים כמות / מוחקים פריט
→ לוחצים "המשך להזמנה" — מגיעים למסך שמבקש התחברות (placeholder או redirect)
```

## קריטריוני קבלה

- [ ] הוספה לעגלה עובדת מעמוד מוצר.
- [ ] עדכון כמות ומחיקה עובדים.
- [ ] סכום מחושב נכון.
- [ ] עגלה נשמרת ברענון דף (במסגרת session מוגדרת).
- [ ] מוצר לא זמין חסום.
